# Claude Instructions

## Project Files

| File | Purpose |
|---|---|
| `README.md` | Project vision, core concepts, architecture overview, and integration targets |
| `BACKLOG.md` | Living backlog of everything that needs to be defined, designed, or built |
| `CLAUDE.md` | This file — instructions and file index for Claude |
| `workflows/INDEX.md` | Index of all workflows with their status |
| `.claude-plugin/plugin.json` | Plugin manifest — name, version, author, keywords |

## General Instructions

- Update this file every time a new file is created, before committing
- Approach all work from the user experience first, then move to implementation
- Keep the backlog up to date: add new items as they are discovered, mark them done when complete
